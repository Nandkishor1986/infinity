# Infinity Computer Institute Management System

MERN starter project for Infinity Computer Institute.

## Stack
- React + Vite
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- Role-based access control

## Project
client/  React frontend
server/  Express backend

## Setup
1. Copy `server/.env.example` to `server/.env`.
2. Set your MongoDB URI and JWT secret.
3. Install dependencies in both folders.
4. Start server and client.

See the individual README files for commands.
